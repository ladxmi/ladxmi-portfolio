# Portfolio · Mickaël Ramandimbimanana

## Ouvrir dans VS Code
1. VS Code → **File → Open Folder…** → choisir ce dossier `portfolio-mickael`.
2. Clic droit sur `index.html` → **Open with Live Server** (extension « Live Server »),
   ou double-cliquer sur `index.html` pour l'ouvrir dans le navigateur.

## Structure
- `index.html`      : le contenu (textes, sections, projets, contact)
- `css/style.css`   : le design (couleurs en haut du fichier, dans `:root`)
- `js/main.js`      : les animations (ciel étoilé, galaxies, texte qui s'écrit…)
- `images/photo.jpg`: votre photo (remplacez-la en gardant le même nom)

## Modifier rapidement
- Couleurs : `css/style.css`, bloc `:root{ ... }` tout en haut.
- Textes : `index.html`, sections `apropos`, `competences`, `projets`, `parcours`, `contact`.
- Mots qui s'écrivent dans l'en-tête : `js/main.js`, liste `var roles=[`.
- Ajouter un projet : copier un bloc `<article class="card"> ... </article>` dans la section `projets`.

Les polices (Google Fonts) nécessitent une connexion Internet.
